# 새 사건 검토의 적용 기준

현재 기준 원문·최신 산출물·관련 인수인계를 확인하고, 사건 목적에 맞는 전문 스킬로 진행한다. 핵심은 민원·부서 의견·확인 사실의 구분, 결론을 바꿀 예외·시점·권한·반대자료, 개인정보 최소화와 판단·문안의 일치다.

분류표·계획표·상태 라벨·보조 파일을 일률적으로 만들지 않는다. 자료가 복잡하거나 다음 작업에서 이어질 판단이 있어야 필요한 기록을 남긴다. 상세 기준은 연결된 기본지침 원본의 `guides/BASE_INSTRUCTIONS.md`, 실행·승인 경계는 현재 작업의 `AGENTS.md`를 따른다.
