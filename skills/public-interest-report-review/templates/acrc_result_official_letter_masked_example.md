# 비식별 구조 예시: 국민권익위원회 공익신고 조사결과 통보 공문

이 문서는 사용자 제공 실무 공문 샘플에서 확인된 번호체계와 문단 순서를 비식별화한 **대외 시행 공문 구조 예시**다. 사건 사실·법령·조치상태의 근거가 아니며, 국민권익위원회 제출용 조사결과 서식 또는 빠른 HWPX 입력 구조와 구분하여 사용한다.

## 적용 상황

- 수신자가 `국민권익위원회위원장(<담당부서장>)`이고, 조사기관이 공익신고 조사결과를 위원회에 회신하는 **시행 공문 본문**을 작성할 때 사용한다.
- `공익신고 조사결과(제출용 서식)` 자체를 작성하거나 빠른 HWPX 입력값을 만드는 경우에는 이 구조 예시가 아니라 별도의 제출용 서식 구조 예시를 사용한다.

## 공문 구조 예시

수신  국민권익위원회위원장(<담당부서장>)

제목  공익신고 조사결과 통보(<접수번호>)

1. 국민권익위원회 <관련문서번호>(20XX. X. X.)와 관련입니다.

2. 위 호로 접수된 공익신고 건에 대한 조사결과를 붙임과 같이 제출합니다.

  가. 공익신고 개요

    1) 접수번호: <접수번호>

    2) 신고제목: <신고제목>

    3) 조사일자: <신고자에게 조사결과를 실제 통보한 날짜>

    4) 조사결과: <핵심 확인결과와 행정·형사상 조치상태를 1~3문장으로 간결히 기재>

붙임  1. 공익신고 조사결과 통보 1부.
      2. 담당부서 조사결과 보고 1부.
      3. 관련 검토자료 1부.  끝.

## 작성 기준

- 제목의 접수번호, 수신부서, 관련문서번호·시행일, 신고제목, 붙임 명칭과 부수는 현재 사건 원자료에서 확인한 값만 사용한다.
- `조사일자`는 **신고자에게 조사결과를 실제 통보한 날짜**를 사용한다. 현장점검일, 담당부서 회신일, 내부 검토일로 대체하지 않는다.
- `조사결과`에는 세부 법리와 조사경위를 장문으로 반복하지 않고 **위반 확인 여부 + 주요 조치상태**를 중심으로 요약한다.
- 조치상태는 `예정 / 진행 / 완료 / 수사의뢰 / 수사결과에 따라 결정 예정` 등을 실제 확인된 상태에 맞게 구분한다.
- 위반이 확인되지 않았거나 객관적 확인이 곤란한 사건도 같은 골격을 사용할 수 있으나, `미확인`, `확인 곤란`, `종결`의 사유와 범위를 실제 조사결과보다 강하게 단정하지 않는다.
- 붙임 1~3은 실무 샘플에서 확인된 기본 흐름일 뿐 고정 필수항목이 아니다. 현재 사건에서 실제 제출하는 자료만 남기고 없는 붙임은 임의로 만들지 않는다.
- 신고자에게 보내는 `공익신고 조사결과 통보` 회신문과 국민권익위원회에 보내는 이 공문을 혼동하지 않는다.
