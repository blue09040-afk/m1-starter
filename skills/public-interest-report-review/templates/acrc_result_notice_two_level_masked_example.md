## 사용 경계

- 확인 사실별로 조치·진행상황이 각각 대응할 때만 이 2단 구조를 사용한다.
- 이 `## 필드명` 구조는 플레이스홀더 기반 HWPX 생성 또는 제출용 서식 값 정리에 사용한다.
- `권익위 조사결과 통보 공문`, `권익위 회신 공문`을 작성할 때는 `acrc_result_official_letter_masked_example.md`를 사용한다.
- `신고자통보일`은 신고자에게 조사결과를 실제 통보한 날짜를 사용한다. 현장점검일, 담당부서 회신일, 내부 검토일로 대체하지 않는다.
- 그 밖의 필드 의미와 값은 현재 사건의 권익위 제출용 서식·공식자료에서 확인한다.
