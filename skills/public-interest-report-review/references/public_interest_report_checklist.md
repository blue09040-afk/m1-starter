# 공익신고 관련 체크리스트

이 체크리스트는 공익신고 사건으로 판단되었을 때 작업 초반에 한 번 숙지하고, 이후 쟁점이 흔들리거나 회신문 작성 기준을 확인할 때 참조하는 기준서이다. 매 문단 또는 매 단계마다 기계적으로 대조하는 용도가 아니다.

## 1. 접수 성격 확인

1. 접수 문서가 공익신고, 일반 민원, 부패신고, 감사요청, 진정, 고충민원 중 어디에 가까운지 먼저 구분한다.
2. 하나의 문서에 여러 성격의 주장이 섞여 있으면 쟁점별로 분리한다.
3. 공익신고로 접수되었다는 사정만으로 모든 주장을 공익침해행위로 보지 않는다.

## 2. 공익신고 기본 요건

다음 요건을 충족하는지 사전 확인한다.

| 점검 항목 | 판단 기준 |
|---|---|
| 공익 관련성 | 국민의 건강·안전, 환경, 소비자 이익, 공정한 경쟁 등 공공의 이익과 관련되는지 |
| 대상 법률성 | 공익신고자 보호법상 공익침해행위 대상 법률과 연결될 수 있는지 |
| 처분 가능성 | 벌칙, 인허가 취소·정지, 시정명령, 과태료 등 제재 또는 행정처분 대상 행위인지 |
| 특정성 | 행위, 대상, 장소, 시기, 관련 법령 또는 위반 유형이 구체적으로 특정되는지 |
| 관할성 | 우리 기관 또는 소관 부서가 조사·처리할 권한이 있는지 |

요건이 불명확하면 공익신고 대상에서 바로 제외하지 말고, `확인 필요`, `보완 필요`, `타 기관 소관 가능`으로 구분한다.

## 3. 검토 대상성 분류

| 분류 | 기준 | 처리 방향 |
|---|---|---|
| 공익신고 검토 대상 | 구체적인 행위, 대상, 장소, 관련 법령 위반 가능성이 특정되고 공익침해행위와 연결될 수 있는 사항 | 소관부서 조사 또는 기존 조사결과와 대조 |
| 일반 민원·감사 참고사항 | 행정의 형평성, 처리 적정성, 업무 태도, 제도 개선 요구 등 공익침해행위로 곧바로 특정하기 어려운 사항 | 회신문에서 별도 성격으로 안내하거나 감사 참고사항으로 관리 |
| 타 기관·별도 절차 사항 | 수사기관, 국세, 금융, 권익위 보상·보호, 다른 행정기관 권한에 속하는 사항 | 관할 기관 또는 별도 절차 안내 |
| 검토 제외 또는 보완 필요 | 업체명, 주소, 위치도 등만 있고 구체적인 위반 행위가 특정되지 않은 사항 | 실체 판단 대상에서 제외하되, 사유를 회신문에 명확히 안내 |
| 기타 등 | 위 네 가지로 명확히 분류하기 어려운 복합·예외 사항 | 성격을 임의 단정하지 말고 확인 필요 사항으로 남기거나 처리 경로를 별도 검토 |

## 4. 소관부서 확인

1. 쟁점을 유형별로 나눈다.
   - 인허가
   - 환경
   - 산지·농지
   - 건축
   - 세무
   - 교통·차량
   - 도로·하천
   - 위생·보건
   - 기타 등
2. 사건 발생지를 확인한다.
   - 주소, 지번, 사업장 소재지, 행위 발생 장소를 기준으로 관할 구청, 읍·면·동, 본청, 사업소, 외부기관 여부를 확인한다.
   - 같은 법령 분야라도 구청별로 인허가·단속·사후관리 담당자가 다를 수 있으므로, 발생지 관할 확인을 생략하지 않는다.
3. 화성시청 공식 홈페이지의 `부서 및 업무 안내`에서 담당업무를 확인한다.
   - 검색어는 법령명, 업무명, 일반 행정용어 수준으로 제한한다.
   - 사건번호, 신고자 정보, 피신고자 개인 인적사항, 상세 주소, 금융정보 등 사건 고유정보는 외부 검색어에 포함하지 않는다.
4. 소관이 불명확하면 임의 배정하지 않고 `[확인 필요]`로 표시한다.
5. 소관부서 판단 근거는 다음 중 하나로 남긴다.
   - 공식 홈페이지 업무분장
   - 조사요청 공문 수신부서
   - 기존 회신 또는 조사결과 제출 부서
   - 내부 확인 결과
   - 확인 필요

## 5. 회신문 작성 기준

1. 공익신고로 검토한 사항과 검토하지 않은 사항을 구분한다.
2. 검토하지 않은 사항은 사유를 안내한다.
   - 구체적 위반 행위가 특정되지 않음
   - 타 기관 소관
   - 별도 신청·보상·보호 절차 사항
   - 일반 민원 또는 감사 참고사항
3. 확인된 사실, 소관부서 판단, 조치 예정·진행·완료를 구분한다.
4. 부서 회신을 인용할 때는 내부 검토를 거친 기관의 처리결과로 정리한다. 특별히 민감하거나 추가 확인이 필요한 부분이 아니라면 `소관부서에서 회신하였습니다`처럼 제3자의 말을 단순 전달하는 문체를 피하고, `조사결과 확인되었습니다`, `위반사항은 확인되지 않았습니다`, `조치할 예정입니다`처럼 감사부서가 종합 검토한 결과로 서술한다.
5. 공익신고 처리 결과에 대한 이의신청 등 법정 안내가 필요한지 확인한다.
6. 공익신고 처리결과는 신고인이 조사결과와 이의신청 필요성을 판단할 수 있을 정도로 구체적으로 통지한다. 단순히 `조사 완료`, `위반사항 없음`, `소관부서 검토 완료`처럼 결론만 통지하지 말고, 필요한 범위에서 다음 사항을 포함한다.
   - 실제 조사한 쟁점
   - 관련 업체명 또는 대상
   - 관련 위치 또는 행위 장소
   - 확인된 행위 또는 확인되지 않은 사항
   - 소관부서 판단
   - 조치 예정·진행·완료 상태
   - 실체 판단 제외 또는 타 기관 소관으로 분류한 사유
7. 처리결과 통지의 구체성은 신고자 비밀보장 및 개인정보 보호와 함께 판단한다. 조사결과 이해에 필요한 업체명, 위치, 위반 여부, 조치상태는 기재할 수 있으나, 신고자 또는 제보자 식별정보와 불필요한 제3자 개인정보는 포함하지 않는다.
8. 공익신고자에게 통지하는 문안은 일반 정보공개 또는 대외 공개문과 다르다. 신고자에게는 처리결과 이해에 필요한 범위의 정보를 제공하되, 불특정 다수에게 공개될 수 있는 문안으로 전용할 경우에는 별도 비식별화와 공개 가능성 검토를 거친다.
9. 답변서에서 신고인이 반드시 확인해야 하는 핵심 내용은 굵게 표시한다. 다만 과도한 강조는 문서의 공신력과 가독성을 떨어뜨리므로, 문단마다 여러 부분을 강조하지 말고 다음 사항 위주로 제한한다.
   - 위반사항 확인 여부
   - 조치 예정·진행·완료 상태
   - 실체 판단 제외 사유
   - 타 기관 또는 별도 절차 안내
   - 개발부담금 등 절차 진행 중인 사항의 현재 상태
   - 이의신청 기간과 방법
   - 개인정보·비밀보장 관련 핵심 안내
10. 답변서의 세부 항목 번호는 원칙적으로 `가. 나. 다.`와 `1) 2) 3)` 체계를 사용한다. `□`, `○` 표시는 내부 검토표나 단순 목록에 한정하고, 대외 회신문 본문에서는 가능한 한 사용하지 않는다.
11. 쟁점별 실제 조사·처리 부서가 둘 이상이면 소제목 끝에 해당 담당부서를 대괄호로 표시한다.
   - 예: `가. 자동차관리사업 등록부지 및 시설요건 관련 [차량등록과]`
   - 예: `나. 건축 인허가 및 대수선 관련 [건축과]`
   - 모든 쟁점을 한 부서가 처리한 경우에는 같은 부서명을 반복하지 않고 생략할 수 있다.
12. 연락처 안내는 총괄부서와 쟁점별 담당부서의 역할이 다른 경우 구분하여 정리한다. 담당자명과 전화번호는 원문 자료 또는 내부 확인으로 확인된 경우에만 기재하고, 확인되지 않은 정보는 임의로 보완하지 않는다.

## 6. 개인정보·비밀보장

1. 신고자 식별정보는 공익신고자 보호법상 비밀보장 대상이므로 내부 검토와 대외 문안 모두에서 최소한으로 처리한다.
2. 신고자에게 조사결과를 통지하는 경우에도 제3자 개인정보, 내부 담당자 개인 연락처, 불필요한 재산·금융 세부정보는 제외한다.
3. 업체명, 위반 위치, 조치결과는 조사결과 이해에 필요한 범위에서만 기재한다.
4. 일반 민원 회신과 공익신고 결과 통지는 공개 범위와 안내 문구가 다를 수 있으므로 일괄 문안을 사용하지 않는다.
5. 공익신고자 보호법상 비밀보장 의무는 신고자등의 인적사항뿐 아니라 신고자등임을 미루어 알 수 있는 사실에도 적용된다. 따라서 신고자와 피신고자 사이의 관계, 내부자만 알 수 있는 경위, 제보 경로, 특정 진술 방식 등으로 신고자를 추정할 수 있는 내용은 문안에서 최소화하거나 일반화한다.
6. 공익신고 처리결과 통지는 신고자에게 하는 것이므로, 조사결과 이해에 필요한 업체명·위치·조치결과를 모두 삭제하는 방식으로 과도하게 축약하지 않는다. 다만 다음 정보는 원칙적으로 제외한다.
   - 신고자 또는 제보자의 이름, 연락처, 주소, 소속, 직위 등 인적사항
   - 신고자 또는 제보자를 추정하게 하는 내부 경위, 제보 경로, 진술 세부내용
   - 피신고자 또는 제3자 개인의 생년월일, 연락처, 가족관계 등 인적사항
   - 내부 담당자 개인 연락처 등 회신에 불필요한 내부 정보
   - 금융거래 세부내역, 담보권 설정 세부사항, 재산 관련 세부자료 등 조사결과 설명에 필수적이지 않은 제3자 재산정보
7. 신고자에게 통지할 수 있는 정보와 외부 공개 가능한 정보는 구분한다. 신고자 통지용 문안, 결재용 내부 검토문, 정보공개·보도자료용 문안은 필요 시 별도로 작성한다.
8. 경계가 불명확한 경우에는 다음 순서로 판단한다.
   - 신고자가 이의신청 여부를 판단하는 데 필요한가
   - 해당 정보 없이도 조사결과와 조치상태를 이해할 수 있는가
   - 해당 정보가 신고자 또는 제3자 개인을 식별하게 하는가
   - 덜 침해적인 표현으로 같은 내용을 설명할 수 있는가
   - 공개 범위가 신고자 통지에 한정되는가, 외부 공개 가능성이 있는가

## 7. 1쪽 최종 점검표

공익신고 답변서 최종본을 발송하거나 결재에 올리기 전 다음 항목을 한 번에 점검한다.

| 점검 항목 | 확인 질문 |
|---|---|
| 최종 기준 파일 | 현재 검토 중인 파일이 사용자가 지정한 최종 답변서인가 |
| 검토 대상성 | 공익신고 검토 대상, 실체 판단 제외, 타 기관·별도 절차 사항이 구분되어 있는가 |
| 사실관계 | 확인된 사실보다 넓게 단정한 표현은 없는가 |
| 소관부서 | 쟁점별 담당부서와 관할이 맞고, 복수 부서가 처리한 경우에만 소제목 표기가 필요한 범위로 되어 있는가 |
| 법령 | 법령명, 조문, 시행일 또는 당시 법령 확인 필요 여부가 정리되어 있는가 |
| 처리결과 통지 | 신고인이 이의신청 여부를 판단할 수 있을 정도로 조사 쟁점, 판단, 조치상태가 설명되어 있는가 |
| 개인정보·비밀보장 | 신고자 식별정보, 불필요한 제3자 개인정보, 금융·재산 세부정보가 제외되어 있는가 |
| 문체 | 제3자 전달식 문체가 아니라 기관이 종합 검토한 처리결과 문체인가 |
| 번호체계 | 대외 회신문 본문이 `가. 나. 다.`와 `1) 2) 3)` 체계로 정리되어 있는가 |
| 강조 | 핵심 내용만 굵게 표시하고 과도한 강조는 피했는가 |
| 이의신청·보상 안내 | 이의신청 기간과 보상금·포상금 등 필요한 법정 안내가 포함되어 있는가 |
| 연락처 | 총괄부서와 쟁점별 담당부서 연락처가 확인된 정보로만 정리되어 있는가 |
| 최근 지시사항 | 작업 마무리 또는 최종 검증 단계에서, 이번 작업 중 새로 합의한 수정 원칙이 최종본에 반영되었는가 |
