# 진정민원 단계별 비식별 샘플 카탈로그

이 파일은 Chat과 Codex가 진정민원 1단계 담당부서 해소계획 요청과 2단계 민원인 답변서를 작성할 때 사용할 비식별 Markdown 구조 예시를 선택하기 위한 라우팅 표이다. 사건 사실은 현재 대화 또는 사건 폴더의 원자료에서만 가져오며, 샘플은 구조 참고용이다.

## 2단계 샘플 선택 순서

1. 사용자가 지정한 현재 사건의 확정 실무 서식이 있으면 그 서식을 우선한다.
2. 별도 확정 서식이 없으면 `기존 처리 재점검형`을 기본으로 검토한다.
3. 단일 쟁점이면 `단순 사실확인형`, 여러 회신 주체의 현황을 집계·통합해야 하면 `현황 집계·복수부서형`, 여러 주장과 권한 한계를 함께 설명해야 하면 `복수쟁점·권한한계형`을 선택한다.
4. 구조를 혼합할 수 있으나, 현재 사건에 없는 사실·법령·부서·조치 항목을 샘플에 맞추어 만들지 않는다.

## 사용 원칙

- 현재 단계의 `active` 기본 샘플 또는 적용 조건에 맞는 `conditional` 샘플을 실제로 읽은 뒤 사용한다.
- 샘플은 구조 예시이므로 사건 사실, 법령, 책임 판단, 담당부서, 날짜를 새 사건에 가져오지 않는다.
- 사용자가 현재 사건의 확정 실무 서식을 지정하면 그 서식을 우선한다.
- 1단계에서는 `< 민원 내용 및 요청사항 정리 >` 외 부분을 사용자 지정 현행 양식의 고정 영역으로 취급한다. 2단계에서는 현재 사건의 확정 답변서 서식을 우선한다.
- Markdown 샘플은 실제 HWP/HWPX 양식의 글상자·표·결재선·페이지 레이아웃을 보증하지 않는다.

## Chat 사용 순서

1. `CHATGPT_ENTRYPOINT.md`에서 진정민원 1단계 또는 2단계 경로를 선택한다.
2. `prompts/chat_mode/진정민원 수행 검토/00_사용안내_및_단계판단.md`와 현재 단계 프롬프트를 적용한다.
3. 이 카탈로그와 선택한 비식별 구조 예시를 실제로 읽는다.
4. 현재 대화에 제공된 사건자료만으로 1단계 요청문 또는 2단계 민원인 답변서를 작성한다.

## 금지

- 실제 사건 원문, HWP/HWPX, 내부 문서번호, 부서·담당자 정보, 주소, 민원번호를 샘플에 누적하지 않는다.
- 샘플 자리표시자를 현재 사건의 확인값처럼 사용하지 않는다.
- 담당부서 회신 전 단계에서 위법·부당·형식적 처리 여부를 감사부서의 결론처럼 확정하지 않는다.
- 담당부서 회신 문구만으로 2단계 사실판단을 확정하거나, 증빙의 미제출을 곧바로 해당 사실의 부존재로 단정하지 않는다.
- 권익위·도권익위원회 외부기관 제출·통보 구조를 일반 진정민원 2단계 답변서 구조로 재사용하지 않는다.
