# 진정민원 해소계획 요청 비식별 샘플 카탈로그

이 파일은 Chat과 Codex가 진정민원 1단계 담당부서 해소계획 요청 초안을 작성할 때 사용할 비식별 Markdown 구조 예시를 선택하기 위한 라우팅 표이다. 사건 사실은 현재 대화 또는 사건 폴더의 원자료에서만 가져오며, 샘플은 구조 참고용이다.

## 현재 등재 샘플

| 단계 | 기본 샘플 | 유형 | 상태 | 채택일 | 사용 조건 |
|---|---|---|---|---|---|
| 진정민원 1단계 담당부서 해소계획 요청 | `01_department_resolution_plan_request_masked_example.md` | 구조 예시 | active | 2026-08-27 | 진정민원 접수 후 담당부서의 현재 해소계획 회신 전, `진정사항 관련 추진내용 및 향후 해소계획` 제출 요청 초안 작성 |

`진정민원 2단계`는 담당부서 해소계획 회신·증빙을 검토하고 민원인 회신 답변서를 작성하는 단계로 역할만 예정 정의되어 있으며, 현재 active 샘플은 없다. 별도 2단계 지침·샘플이 채택되기 전에는 1단계 샘플을 2단계 회신문 형식으로 재사용하지 않는다.

## 사용 원칙

- 현재 단계의 active 샘플을 실제로 읽은 뒤 사용한다.
- 샘플은 구조 예시이므로 사건 사실, 법령, 책임 판단, 담당부서, 날짜를 새 사건에 가져오지 않는다.
- 사용자가 현재 사건의 확정 실무 서식을 지정하면 그 서식을 우선한다.
- `< 민원 내용 및 요청사항 정리 >` 외 부분은 사용자 지정 현행 양식을 고정 형식으로 취급한다. 사용자가 별도 수정을 요청하지 않으면 임의로 재작성하지 않는다.
- Markdown 샘플은 실제 HWP/HWPX 양식의 글상자·표·결재선·페이지 레이아웃을 보증하지 않는다.

## Chat 사용 순서

1. `CHATGPT_ENTRYPOINT.md`에서 진정민원 1단계 경로를 선택한다.
2. `prompts/chat_mode/진정민원 수행 검토/00_사용안내_및_단계판단.md`와 `01_1단계_담당부서_해소계획요청.md`를 적용한다.
3. 이 카탈로그와 `01_department_resolution_plan_request_masked_example.md`를 실제로 읽는다.
4. 현재 사건의 원문과 직접 연결되는 기존 수·발신 자료만으로 `< 민원 내용 및 요청사항 정리 >`를 작성한다.

## 금지

- 실제 사건 원문, HWP/HWPX, 내부 문서번호, 부서·담당자 정보, 주소, 민원번호를 샘플에 누적하지 않는다.
- 샘플 자리표시자를 현재 사건의 확인값처럼 사용하지 않는다.
- 담당부서 회신 전 단계에서 위법·부당·형식적 처리 여부를 감사부서의 결론처럼 확정하지 않는다.
