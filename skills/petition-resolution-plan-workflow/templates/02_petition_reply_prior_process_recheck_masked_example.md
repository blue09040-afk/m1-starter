# 비식별 구조 예시: 진정민원 2단계 기존 처리 재점검형

이 문서는 담당부서 회신과 증빙을 받은 뒤 기존 처리경위, 추가 확인, 보완조치와 종합 판단을 설명하는 **기본 구조 예시**이다. 실제 사건을 마스킹한 자료가 아니며, 자리표시자를 사실·법령·책임 판단의 근거로 사용하지 않는다.

## 적용에 맞는 경우

- 같은 쟁점에 관한 앞선 민원과 회신이 있음
- 이번 1단계 요청에 따라 담당부서가 자료를 제출했고 추가 확인 또는 보완도 이루어짐
- 민원인에게 기존 처리와 이번 재점검 결과가 어떻게 다른지 설명할 필요가 있음

## 구조 예시

```text
1. 귀하의 가정에 평안과 행복이 가득하시기를 기원합니다.

2. 귀하께서 제기하신 민원은 <기존 처리의 적정성, 사실관계 또는 후속조치>에 관한 사항으로 이해되며, 이에 대한 검토 결과는 다음과 같습니다.

가. 검토 결과

  1) 기존 민원 처리 경위
    - <앞선 민원의 문제 제기와 요구사항>
    - <당시 담당부서의 확인 과정, 제출자료와 회신 결론>

  2) 담당부서 제출자료 및 추가 확인 내용
    - <이번 1단계 요청에 대한 담당부서 회신의 구체적 내용>
    - <제출 증빙과 추가 확인으로 확인된 사실·기준시점>
    - <수치·기술사항이 쟁점인 경우 산식·대상기간·단위·원자료를 다시 확인한 결과>

  3) 추가 문제 제기 후 재확인 및 보완조치
    - <추가 또는 반복 민원으로 다시 확인하게 된 쟁점>
    - <재확인 결과와 보완자료 제출·시정·안내 개선 등 실제 조치>
    - <아직 완료되지 않은 조치의 현재 상태와 향후 계획>

  4) 관련 기준 검토 및 <핵심 주장> 해당 여부
    - <현재 사건에 적용되는 공식 기준과 적용 범위>
    - 현재까지 제출된 자료와 추가 확인 결과, <쟁점별 결론과 핵심 이유>입니다.
    - 다만 <자료상 미확인 또는 권한상 판단할 수 없는 범위>는 <그 한계와 가능한 별도 절차>를 안내드립니다.

3. 본 회신에 대한 추가 설명이 필요하신 경우 <담당 부서·직위·연락처>로 문의하여 주시기 바랍니다.

붙임  <실제 첨부자료가 있는 경우에만 기재> 1부.  끝.
```

## 사용 점검

- 담당부서의 설명과 증빙으로 확인된 사실을 구분한다.
- 보완 전 상태와 보완 후 상태를 섞지 않는다.
- `문제가 없음` 같은 결론만 적지 않고 핵심 근거를 함께 제시한다.
- 미완료 조치를 완료된 것처럼 쓰지 않는다.
