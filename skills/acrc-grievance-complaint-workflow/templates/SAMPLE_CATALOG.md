# 권익위 고충민원 비식별 샘플 카탈로그

### 2단계에서 확인된 공통 구조와 변형

- 완료된 2단계 결재문 3건을 대조한 공통 골격은 기본 샘플 `02_acrc_submission_masked_example.md`에 반영했다. 세부 문단 순서의 정본은 해당 파일이며, 이 카탈로그에는 적용 조건과 확인된 변형만 기록한다.
- 3건 모두 본문 대항목은 `가.`와 `나.`의 2단 구성이었고 붙임은 2묶음이었다. 권익위 요구사항이 상세하더라도 담당부서 검토의견·설명자료가 붙임이면 `발생경위`, `검토결과`, `해소대책`을 본문 대항목으로 자동 신설하지 않고 `나. 화성시 의견`에 쟁점별로 압축한다.
- 붙임 2묶음은 공통 구조 확인 결과일 뿐 고정 서식이 아니다. 현재 사건의 공식 요청문과 실제 첨부자료에 따라 명칭·수량·구성을 조정한다.

| 확인된 변형 | 참조 샘플 | 적용 조건 |
|---|---|---|
| 권한·법령상 한계형 | `02_acrc_submission_authority_limit_masked_example.md` | 행정기관이 신청인의 요구를 직접 강제하기 어렵고 협의·안내·지원 등 가능한 조치를 구분해야 하는 경우 |
| 처분·절차 진행형 | `02_acrc_submission_pending_procedure_masked_example.md` | 확정된 경과, 진행 중 절차와 조건부 후속조치를 시간·상태별로 구분해야 하는 경우 |
| 직접 규정 미비·제도개선형 | `02_acrc_submission_regulatory_gap_masked_example.md` | 현장 확인 결과와 현행 법령상 직접 수단의 한계, 제도개선 계획을 구분해야 하는 경우 |

세 변형은 모두 `구조 예시`이며 완료 문서의 사건번호, 기관·부서명, 주소, 성명, 연락처, 문서번호, 날짜, 결재정보와 고유 사실을 포함하지 않는다. 실제 사건의 내용 근거로 재사용하지 않는다.

### 3단계에서 확인된 구조 변형

- 제목은 `고충민원 처리결과 통보(...)`가 기본이지만, 확정 실무 샘플에 따라 `고충민원 처리결과 알림(...)`을 사용할 수 있다.
- 민원번호 접두어와 세부 형식은 샘플마다 다를 수 있으므로, 특정 샘플 값을 새 사건에 복사하지 않고 현재 사건 공식자료에서 확인한다.
- 민원 항목 표제는 `민원요지`, `민원요지(주장)`, `민원내용`, `민원내용(주장)` 변형이 확인되므로 현재 사건의 앞 단계 확정 표제 또는 사용자 지정 샘플을 우선한다.
- 민원 항목이 하나인 경우 한 문장 또는 하위 글머리표로 작성된 사례가 있고, 여러 쟁점인 경우 `1)`, `2)` 등으로 나눈 사례가 있다. 쟁점 수를 형식에 맞추기 위해 임의로 늘리지 않는다.
- 대부분은 `민원 항목 → 권익위 의견`의 2단 구성이다. `화성시 의견`은 앞 단계에 해당 의견이 존재한다는 이유만으로 신설하지 않고, 현재 사건의 사용자 지정 샘플·기존 결재형식이 3단 구조를 사용하거나 권익위 처리결과 원문상 분리하지 않으면 결과 취지가 달라질 우려가 있을 때만 `민원 항목 → 화성시 의견 → 권익위 의견`의 3단 구성을 사용한다.
- 붙임은 실제 자료에 따라 `국민권익위원회 공문 + 민원 회신문` 또는 `국민권익위원회 공문`만 둘 수 있다.
- 처리유형이 국민권익위원회의 **제46조제2항 의견표명**으로 확인되면 위 3단계 변형을 적용하지 않고 4단계 샘플로 전환한다.
- 제47조에 따른 제도개선 의견표명은 현재는 3단계에서 처리하되, 법 제50조제1항의 30일 처리결과 통보와 시행령 제51조의 곤란 사유 통보 등 법정 후속절차를 별도로 확인한다.

### 4단계 의견표명 구조

- 기본 골격은 `1. 관련문서 → 2. 의견표명 사실 및 ○ 주문 → 3. 법 제50조제1항의 존중·30일 처리결과 통보 및 시행령 제51조제1항의 곤란 사유 통보 → 4. 담당부서 내부 회신 요청 → 5. 법 제53조의 공표 가능성·법 제26조제1항의 운영상황 연례 보고·공표 및 감사부서 관리 안내 → 붙임`이다.
- `○ 주문`은 의결서 주문의 기관 조치 부분을 원문 취지대로 전달하고, 감사부서가 별도 의무·책임 판단을 추가하지 않는다.
- 내부 회신기한은 현재 사건에서 확인·확정된 값을 사용하며, 권익위의 법정 후속기한을 고려하더라도 임의 날짜를 만들지 않는다.
- 개별 권고·의견표명 내용과 제50조제1항 처리결과의 공표 가능성은 법 제53조에 근거하며, 법 제26조제1항은 고충민원 관련 위원회 운영상황의 연례 대통령·국회 보고 및 공표 근거로 구분한다.
- 적극행정 면책과 기관평가 안내는 감사부서의 이행관리 목적상 포함할 수 있으나, 내부규정 조문번호·평가명·수용률 반영기준은 작성 시점의 현행 기준을 확인한다.
- 의결 이유에 조례개정·제도개선 필요성이 포함되어 있어도 주문과 구분하며, 별도 의무처럼 확대하지 않는다.
- 붙임은 실제 권익위 처리결과 통보 공문과 의결서 등 현재 사건 첨부자료와 일치시킨다.

완성 문체를 재사용하는 `문안 예시`는 아직 기본 샘플로 등재하지 않았다. 확정 문서를 후보로 삼을 때는 `skills/guidance-repo-maintenance/references/deidentified_sample_publishing_standard.md`와 `skills/acrc-grievance-complaint-workflow/references/sample_form_lifecycle.md`를 적용한다.

## Chat 사용 순서

1. `CHATGPT_ENTRYPOINT.md`와 `prompts/chat_mode/권익위 수행 검토/00_사용안내_및_단계판단.md`로 단계를 판단한다.
2. 이 카탈로그에서 해당 단계의 기본 샘플을 실제로 연다.
3. 선택한 샘플 파일명과 유형을 짧게 밝히고, 현재 사건 원자료만으로 초안을 작성한다.
4. 파일을 열 수 없으면 읽었다고 가정하지 말고 경로와 미열람 사실을 알린다.

## 금지

- 샘플의 `20XX`, `0000`, `ㅇㅇ`, `<민원번호>` 같은 자리표시자를 현재 사건의 확인값처럼 사용하지 않는다.
- 샘플만으로 사건번호, 담당부서, 처리유형, 기한과 붙임을 확정하지 않는다.
- Markdown 샘플을 실제 HWPX/ODT 양식이나 레이아웃 보증으로 취급하지 않는다.
- `구조 예시`를 추상 필드 목록으로 다시 재구성하여 실제로 확정된 문단 순서를 바꾸지 않는다. 현재 사건의 사용자 지정 샘플이 있으면 그 샘플을 우선한다.
