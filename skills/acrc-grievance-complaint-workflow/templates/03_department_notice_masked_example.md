# 비식별 구조 예시: 3단계 처리결과 담당부서 통보

이 문서는 복수의 사용자 확정 실무 샘플에서 공통 확인된 **문단 순서와 필드 구조만** 비식별화한 구조 예시이다. 실제 사건 원문을 자동 마스킹한 자료가 아니며, 사건 사실·처리유형·기한의 근거로 사용하지 않는다.

## 수신
ㅇㅇ부서장

## 제목
고충민원 처리결과 통보(<민원번호>)

- `통보`를 기본 예시로 두되, 현재 사건의 확정 샘플·기존 문서가 `알림`을 사용하면 그 표제를 유지한다.
- 민원번호의 접두어와 형식은 현재 사건 공식자료에서 확인한다. 실무 샘플마다 서로 다른 형식이 확인되므로 구조 예시의 값을 새 사건에 복사하거나 추정하지 않는다.

## 본문 기본 구조

1. 국민권익위원회 ㅇㅇ과-0000(20XX. 1. 1.)호와 관련입니다.

2. 국민권익위원회에 접수된 고충민원과 관련하여 붙임과 같이 신청인에게 회신하였음을 알려드리니 업무에 참조하시기 바랍니다.

가. 민원요지
  1) [앞 단계에서 확정한 첫 번째 핵심 주장 또는 요구]
  2) [앞 단계에서 확정한 두 번째 핵심 주장 또는 요구]

나. 권익위 의견
  1) [권익위 처리결과 원문에서 확인되는 주요 판단·확인내용]
  2) [권익위의 최종 처리유형과, 원문에 있는 경우 향후 관리·이행사항]

## 선택 변형 — 화성시 의견을 별도 구분해야 하는 경우

앞 단계에 화성시 의견이 존재한다는 사정만으로 이 항목을 신설하지 않는다. 현재 사건의 사용자 지정 샘플·기존 결재형식이 3단 구조를 사용하거나, 권익위 처리결과 원문이 화성시 의견과 권익위 최종 판단을 명확히 분리하고 이를 합쳐 쓰면 결과 취지가 달라질 우려가 있는 경우에만 아래처럼 구성한다.

가. 민원요지
  [핵심 주장 또는 요구]

나. 화성시 의견
  1) [앞 단계에서 공식 제출·확인된 화성시 의견]
  2) [필요한 경우 추가 항목]

다. 권익위 의견
  [권익위 최종 처리유형 또는 판단. 간단한 각하·종결 등은 한 문장으로 정리 가능]

## 붙임
1. 국민권익위원회 공문 1부.
2. 민원 회신문 1부.  끝.

## 적용 메모

- 공통 골격은 `1. 관련문서 → 2. 신청인 회신 통보 → 가. 민원요지/민원내용 → (필요시 화성시 의견) → 권익위 의견 → 붙임`이다.
- 민원 항목 표제는 실무 확정본에서 `민원요지`, `민원요지(주장)`, `민원내용`, `민원내용(주장)`이 모두 확인된다. 현재 사건의 앞 단계 확정 표제 또는 사용자 지정 샘플을 우선하고, 별도 기준이 없으면 `민원요지`를 기본으로 한다.
- 민원 항목이 하나인 확정본에서는 한 문장이나 하위 글머리표로 작성된 사례도 있고, 여러 쟁점인 경우 `1)`, `2)`로 나눈 사례도 확인된다. 쟁점 수와 현재 사건의 확정 문체에 맞추고 형식상 항목 수를 억지로 늘리지 않는다.
- 2항 말미의 `업무에 참조하시기 바랍니다`와 `업무에 참고하시기 바랍니다`는 현재 사건의 확정 샘플·기존 문체를 따른다. 별도 기준이 없으면 `참조`를 기본으로 한다.
- `화성시 의견`은 위 선택 조건이 충족되는 경우에만 신설한다. 해당 항목을 사용하면 `권익위 의견`은 `다.`로 순연한다.
- `권익위 의견`은 원문에서 확인되는 내용만 정리한다. 권고·의견표명·합의·심의안내·각하·기각·종결 등 처리유형을 임의로 바꾸지 않는다.
- 권익위가 별도 조치계획·결과 제출이나 기한을 요구하지 않았다면 `후속조치`, `기한`, `요청사항` 같은 별도 항목을 임의로 신설하지 않는다. 필요한 관리사항은 원문과 앞 단계 제출의견 범위에서 해당 의견 항목에 반영한다.
- 붙임은 실제 첨부자료만 적는다. 민원 회신문이 첨부되지 않는 사건에서는 `국민권익위원회 공문 1부.`만 둘 수 있다.
- 실제 HWPX/ODT의 결재선·시행부·레이아웃은 이 Markdown 구조 예시가 보증하지 않는다.
