# 권익위 고충민원 사건 교체

사용자가 `새 사건으로 교체`, `새 건으로 교체`, `사건 교체`라고 요청하면 현재 사건자료와 산출물을 하나의 날짜·사건번호 보관 폴더로 보존 이동한다.

## 처리 순서

1. 현재 사건번호와 사건 귀속 자료를 확인한다.
2. 결재 문서 등 주요 파일의 잠금 여부를 확인한다.
3. 현재 사건의 결재준비, 권익위 요청·1단계 자료, 담당부서 회신, 검토작업, `HANDOFF_SUMMARY.md`를 하나의 고유한 보관 폴더로 이동한다.
4. 공통 지침과 비식별 구조 예시는 이동하지 않는다.
5. 이동 전후 목록을 대조하고 남은 사건자료, 실패 항목과 실제 위치를 보고한다.

## 안전 경계

- 삭제하거나 덮어쓰지 않는다.
- 같은 이름이 있으면 고유 접미사를 사용한다.
- 잠긴 파일, 귀속이 불명확한 파일, 충돌 파일은 이동하지 않는다.
- 이전 사건 보관 폴더는 새 사건 판별에서 제외하고, 사용자가 과거 사건 확인을 요청할 때만 연다.
- 중앙 기본지침이 연결되지 않았으면 절대경로를 추정하지 말고 연결 필요를 알린다.
