# 작업 교훈 추출 프롬프트

다음 작업을 마무리하면서, 공통 지침으로 재사용할 수 있는 교훈과 사건 고유 정보를 분리해 주세요.

## 입력

- 작업 폴더:
- 최종 산출물:
- 사용한 주요 자료:
- 실패했거나 우회한 도구:
- 사용자가 새로 정한 기준:

## 수행 기준

1. 사건 고유 사실, 개인정보, 내부 문서번호, 담당자 정보는 공통 지침 후보에서 제외한다.
2. 반복 가능한 절차, 검증 기준, 도구 실패·대체절차, 문안 기준만 추출한다.
3. 단순 취향이나 일회성 지시는 후보로 올리지 않는다.
4. 후보는 반영 위치를 제안하되, 즉시 반영하지 말고 사용자 확인이 필요한 항목을 구분한다.
5. 이미 기존 지침에 있는 내용은 중복 반영하지 않고 강화 필요 여부만 적는다.
