# 웹·자료검색 정본

최종 검토: **2026-09-16**

이 문서는 이 starter의 **민원·행정 자료검색 도구 선택, 크레딧 통제, 웹 PDF 취급, 전용 도구 장애 시 우회** 정본이다. 사건 판단·법령 해석 자체의 정본은 아니다.

- 법령 확인 절차의 정본은 `guides/BASE_INSTRUCTIONS.md` 17·17-1·17-2이다. 그 본문을 여기 복제하지 않는다.
- 화성시 담당부서·담당자 확인의 정본은 `hwaseong-staff-lookup`이다. 그 본문을 여기 복제하지 않는다. 화성시가 아니면 해당 기관의 공식 조직·직원검색을 우선한다.
- PDF 판독의 정본은 `pdf-reading-kit`이다. 이 문서는 **어떤 경로로 웹 PDF 원문을 확보·열지**만 정한다.
- 일반 기술·학술·뉴스·장소 검색은 이 문서의 대상이 아니며, 현재 실행환경과 사용자가 정한 일반 검색 정책을 따른다.

GitHub 저장소 파일은 현재 환경에서 허용된 GitHub 플러그인 또는 MCP로 읽고, Firecrawl로 읽지 않는다. 커넥터를 쓸 수 없으면 토큰 추출·Firecrawl 등으로 우회하지 말고 미확인 상태를 보고한다.

## 1. 민원·행정 자료검색 기본 순서

앞 단계에서 결론에 필요한 공식 원문이 확보되면 같은 목적의 검색 도구를 추가하지 않는다.

1. **첨부·사건폴더 원문.** 이미 있는 공문, 고시, 도면, 회신, 화면 캡처를 먼저 읽는다.
2. **전용 공식 경로.**
   - 법령·조례·행정규칙: 사용 가능한 법령정보 MCP 또는 국가법령정보센터 등 공식 원문
   - 화성시 담당부서·담당자: `hwaseong-staff-lookup`
   - 필지·토지이용: 브이월드 MCP 또는 해당 공식 지적·토지이용 서비스
3. **공식 URL 발견.** 공식 주소를 아직 모를 때는 Web 검색을 **공식 원문 발견용으로 최소 사용**할 수 있다. 공식 페이지를 찾으면 검색 결과 요약으로 결론내리지 말고 해당 원문을 직접 확인한다. 같은 질문을 여러 검색 도구에 연속 호출하지 않는다.
4. **공식 HTML.** 확인된 해당 페이지만 읽는다. 같은 기관 사이트 전체를 crawl하지 않는다.
5. **웹 PDF.**
   - 일반 Chat에 네이티브 PDF 열기·페이지 보기 기능이 있으면 공식 PDF를 그 경로로 직접 확인한다.
   - Codex·로컬 작업처럼 파일 기반 판독이 필요한 환경에서는 PDF를 내려받아 `pdf-reading-kit`으로 읽는다.
   - 현재 환경에서 원문 PDF를 실제로 열 수 없으면 공식 주소를 제시하거나 사용자 첨부를 요청한다.
   - Firecrawl로 PDF를 scrape/parse하지 않는다.

검색 입력에는 **현재 조회에 꼭 필요한 식별자만** 쓴다. 필지·건축물 조회의 지번·주소처럼 조회키 자체가 필요한 경우는 사용할 수 있다. 민원인 성명·연락처·내부 식별자는 필요하지 않으면 넣지 않고, **공유·재사용 지침·예시·로그**에는 사건 고유 식별자를 남기지 않는다.

## 2. Firecrawl

민원·행정 자료검색의 기본 경로는 Firecrawl이 아니다. **기본값은 호출 0회**이다.

다음 조건을 모두 만족할 때만 예외적으로 사용한다.

- 대상이 PDF가 아닌 공식 HTML임
- 확인할 정확한 URL 또는 매우 좁은 대상 페이지가 이미 특정됨
- 전용 커넥터나 일반 직접 열기로는 필요한 본문을 확인할 수 없음
- 구조화·JS 렌더링 등 Firecrawl을 써야 결론의 정확성 또는 실행 가능성이 실제로 개선됨

금지:

- PDF scrape/parse
- `--query`형 고비용 추출을 단순 사실확인에 사용
- crawl
- 사이트 통째 다운로드
- 전용 MCP 장애를 이유로 한 광역 검색
- 같은 질문을 다른 검색도구와 중복 호출해 결과 수만 늘리기

크레딧 숫자를 이 정본에 고정하지 않는다. 운영 원칙은 **불필요한 유료 호출, 고비용 query, 대량 crawl, PDF 파싱 금지**이다.

## 3. 전용 도구 장애 시 우회

전용 도구가 없거나 실패하면 실패 경로를 확인하고 아래처럼 최소 우회한다.

| 대상 | 우회 | 하지 말 것 |
|---|---|---|
| 법령·조례·행정규칙 | 국가법령정보센터 등 공식 원문. URL을 모르면 Web으로 공식 페이지를 발견한 뒤 원문 확인 | 검색결과 요약만으로 조문 확정 |
| 화성시 담당부서 | 공식 직원검색·조직 페이지. URL을 모르면 Web으로 공식 페이지 발견 | 직원명단 대량 스크래핑 |
| 필지·토지이용 | 다른 공식 지적·토지이용 서비스 또는 사용자 화면. 공식 URL 발견에 한해 Web 최소 사용 | 포털 결과만으로 토지정보 확정 |
| 공식 안내 HTML | 확인된 해당 페이지. URL 미확인 시 Web으로 공식 페이지 발견 | 사이트 crawl, 유사 페이지 대량 수집 |
| 웹 PDF | Chat 네이티브 PDF 확인 또는 파일 입수 후 로컬 판독 | Firecrawl PDF 파싱 |
| GitHub 파일 | 현재 환경에서 허용된 GitHub 플러그인/MCP | Firecrawl로 저장소 읽기 |

우회가 불가능하면 확인하지 못한 상태로 보고한다. 부족한 근거를 검색 횟수로 메우지 않는다.

## 4. Chat과 Codex

- **Codex:** 전용 공식 경로를 먼저 쓰고, 도구 선택·fallback·Firecrawl 사용 여부가 쟁점일 때 이 파일을 확인한다. PDF를 로컬 파일로 확보했다면 `pdf-reading-kit`을 적용한다.
- **일반 Chat:** 전용 공식 경로와 직접 원문 확인을 우선한다. 공식 URL을 모르면 Web을 발견용으로 최소 사용하고, 웹 PDF는 현재 Chat의 네이티브 PDF 열기·페이지 확인 기능이 있으면 그 기능을 사용한다. Codex 로컬 스크립트 실행을 Chat의 의무로 가져오지 않는다.
- `admin-source-lookup`은 업무별 전용 경로를 먼저 고르고, **도구 선택이 애매하거나 fallback·크레딧 통제가 필요한 경우** 이 정본으로 연결한다.

## 5. 지양할 패턴

- 공식 전용 경로가 있는데 처음부터 범용 검색에 맡기는 것
- 전용 MCP가 실패했다고 같은 질문을 여러 검색 도구에 연속 호출하는 것
- 검색결과 스니펫만 보고 법령·담당부서·필지 정보를 확정하는 것
- 공식 HTML이 열리는데도 Firecrawl로 다시 추출하는 것
- 웹 PDF를 페이지 수와 관계없이 Firecrawl로 읽는 것
- 실제 조회에 필요하지 않은 민원인·내부 식별자를 검색어에 넣는 것
- 공유·재사용 예시·로그에 사건 고유 지번·민원인·내부 식별자를 남기는 것
- GitHub 지침 파일을 Firecrawl로 읽는 것
