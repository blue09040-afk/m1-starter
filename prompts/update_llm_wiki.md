# LLM Wiki 정리 프롬프트

이번 작업에서 재사용 가능한 업무지식, 문안 원칙, 도구 운영 노하우, 개선사항, 비식별 작업이력 색인을 `LLM_Wiki/`와 `improvements/` 기준에 맞게 정리해 주세요.

## 입력

- 작업 폴더:
- 작업 목적:
- 최종 산출물:
- 주요 산출물 파일명:
- 새로 확인한 반복 지식:
- 도구 실패 또는 우회 절차:
- 사용자가 새로 정한 기준:

## 수행 기준

1. 개인정보, 민원인·신고자·담당자 식별정보, 상세 주소, 비공개 검토자료는 제외한다.
   - 내부 문서번호는 일반지식·문안 원칙·개선사항 본문에는 넣지 않는 것을 기본으로 한다.
   - 다만 나중에 자료를 찾기 위한 색인 가치가 큰 경우, `LLM_Wiki/작업이력/`에는 문서번호만으로 민원인·담당자·상세 주소가 직접 식별되지 않는 범위에서 최소 기재할 수 있다.
   - 내부 문서번호를 작업이력 색인에 남길 때는 해당 문서번호가 공개·공유 대상이 아니라 로컬 업무검색용 색인임을 전제로 하고, 문서 본문·결재선·담당자명·상세 주소와 함께 적지 않는다.
2. 사건 고유 사실은 `LLM_Wiki/`나 공통 지침 후보에 넣지 않고, 필요한 경우 사건 폴더 산출물 또는 `HANDOFF_SUMMARY.md`에만 남긴다.
3. `LLM_Wiki/`에는 사람이 찾기 쉬운 일반지식, 비식별 사례 패턴, 문안 원칙, 도구 운영 요약, 개선사항 색인, 비식별 작업이력 색인만 작성한다.
4. 공통 지침으로 승격할 가능성이 있는 항목은 `improvements/candidate_lessons.md`에 후보로 기록한다.
5. 이미 반영된 사항은 `improvements/adoption_log.md`와 기존 지침을 확인해 중복 기록하지 않고, 필요한 경우 `LLM_Wiki/개선관리/`에 찾아가기 링크만 보강한다.
6. 오래되었거나 충돌 가능성이 있는 지침은 `improvements/stale_review_log.md` 후보로 분리한다.
7. 최신 법령, 담당부서, 정책, 도구 버전처럼 변동 가능한 정보는 확인일 또는 `확인 필요` 상태를 표시한다.
8. 단순 문안 수정, 일회성 자료 정리, 사건 특수 판단만 있는 경우에는 `LLM_Wiki/` 일반지식·문안 원칙 갱신을 생략할 수 있다. 다만 작업 종료 단계에서 사건 폴더 산출물이나 `HANDOFF_SUMMARY.md`가 생성·갱신된 경우에는, 공통 일반지식으로 반영할 내용이 없어도 `LLM_Wiki/작업이력/` 비식별 색인 작성 여부를 별도로 판단한다.
9. Obsidian CLI를 사용할 수 있으면 정리 후 vault 또는 반영 노트를 여는 확인 보조 수단으로만 사용한다. CLI로 개인정보·사건 원문을 가져오거나, `improvements/`와 `LLM_Wiki/`를 무검토 자동 동기화하지 않는다.
10. 작업이력 색인을 남길 때는 작업유형, 비식별 주제, 축약 작업 폴더, 주요 산출물 파일명, 다음에 먼저 볼 파일을 기록한다. 필요한 경우 최소한의 내부 문서번호를 검색 키로 남길 수 있으나, 상세 사건 사실·판단·확인 필요 사항은 작업 폴더의 `HANDOFF_SUMMARY.md`에만 둔다.
11. 사용자가 `마무리하자`, `인수인계`, `최종 정리`, `작업 종료`처럼 종료 지시를 하면, `HANDOFF_SUMMARY.md` 작성 또는 갱신, 반복 가능한 개선사항 추출, `LLM_Wiki/` 반영 필요 여부를 함께 점검한다. 이때 `LLM_Wiki 일반지식·문안 원칙`과 `LLM_Wiki 작업이력 색인`을 분리해 판단한다.
12. 사건 폴더에서 의미 있는 산출물, 검증 결과, 최종 문안, HWPX/PDF 판독 결과, 또는 `HANDOFF_SUMMARY.md`가 남은 경우에는 `LLM_Wiki/작업이력/YYYY/YYYY-MM_작업이력.md` 색인을 기본 작성한다. 생략할 수 있는 경우는 파일 산출물이 없는 짧은 질의응답, 단순 한 줄 수정, 또는 나중에 찾을 업무검색 가치가 낮은 작업으로 한정하고, 생략 사유를 적는다.
13. 마무리 최종 보고에는 `LLM Wiki 일반지식: 반영함 / 반영할 내용 없음 / 생략함(사유)`와 `LLM Wiki 작업이력: 반영함 / 생략함(사유)`를 구분해 포함한다. 실제 반영이 없더라도 점검 결과를 생략하지 않는다.

## 권장 정리 위치

- 업무처리 일반지식: `LLM_Wiki/LLM_Wiki/업무처리 일반지식/`
- 문안 표현: `LLM_Wiki/LLM_Wiki/문안 표현/`
- 법령검토 방법: `LLM_Wiki/LLM_Wiki/법령검토 방법/`
- 담당부서 업무분류: `LLM_Wiki/LLM_Wiki/담당부서 업무분류/`
- 도구 업무자동화: `LLM_Wiki/LLM_Wiki/도구 업무자동화/`
- 개선관리 색인: `LLM_Wiki/LLM_Wiki/개선관리/`
- 작업이력 색인: `LLM_Wiki/LLM_Wiki/작업이력/YYYY/YYYY-MM_작업이력.md`
