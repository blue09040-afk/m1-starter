# 새 사건 검토 시작 프롬프트

한국 행정·민원·감사·조사 사건이면 `admin-document-base-review`를 적용하세요. 상세한 공통 판단 기준이 필요한 경우에만 `guides/BASE_INSTRUCTIONS.md`의 관련 절을 참조하세요.

공익신고 사건이면 `public-interest-report-review` 스킬을 함께 적용하세요.

## 작업 요청

1. 먼저 `HANDOFF_SUMMARY.md`가 있는지 확인하고, 있으면 읽은 뒤 이어서 작업하세요.
2. `HANDOFF_SUMMARY.md`가 없으면 신규 사건으로 보고 폴더 구조와 주요 파일의 성격을 파악하세요.
3. 신고자 제출자료, 소관부서 검토자료, 감사부서 조사요청 공문, 기존 추출자료, 기존 검토 산출물을 구분하세요.
4. 본문 작성 전에 사건 성격을 진단하세요.
5. 필요한 산출물과 작업 순서를 짧게 알린 뒤, 안전하고 요청 범위 안에서 가능한 조사준비 작업은 계속 진행하세요.
6. 자료가 방대하거나 산출물이 여러 개이면 하네스 적용 필요성을 판단하고, 필요한 경우에만 `guides/harness_structure_guide_v1_3.md`를 확인해 작업 단위·로그·산출물·검증 흐름을 설계하세요.
7. 현재 세션 정책과 도구가 허용하고 독립 작업의 병렬화가 실질적인 이점이 있으면 서브에이전트를 활용할 수 있습니다. 사용자의 명시적 요청은 필수 조건이 아닙니다.
8. 사용자 선택이 결과를 크게 바꾸거나 새로운 권한·외부 전송·파괴적 변경이 필요한 경우에만 진행을 멈추고 확인하세요.
9. 자료가 방대하면 기존 추출자료와 기존 산출물을 우선 활용하여 리소스 낭비를 줄이세요.
10. PDF·HWPX 읽기의 기본값은 마스킹 없음입니다. 사용자 또는 작업 프로필이 마스킹을 명시한 경우에만 텍스트용 또는 시각 마스킹용 경로를 선택하고, 업무상 남겨야 할 담당자 성명·업무 연락처는 정확한 보존값으로 지정하세요. 마스킹을 이유로 외부 OCR·변환 승인을 추정하지 마세요.

## 산출물 설계 기준

산출물은 고정하지 말고 사건 성격에 따라 설계하세요. 필요하면 다음 중 선택하거나 조합하세요.

- 주장 분류표
- 소관부서·쟁점 대조표
- 법령 확인 목록
- 확인 필요 항목
- 회신문 초안
- 결재자용 위험요약
- 자동검증 산출물
- 인수인계 요약

## 판단 표시 방식

각 주요 판단에는 가능한 한 상태를 붙이세요.

- `확정`
- `잠정`
- `확인 필요`
- `법령 확인 필요`
- `검토 제외`
- `타 기관 소관`

고의, 유착, 사기, 포탈, 특혜, 징계 수위처럼 위험한 표현은 근거가 충분하지 않으면 확정하지 말고, 소관기관 또는 별도 절차 사항으로 분리하세요.
