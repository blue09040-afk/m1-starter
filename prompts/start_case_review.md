# 새 사건 검토 시작 프롬프트

이 사건의 현재 자료와 요청을 검토해 업무에 바로 쓸 수 있는 결과물을 작성하세요.

- 현재 기준 원문과 최신 산출물을 확인하고, 관련 HANDOFF가 있으면 이어서 진행하세요.
- `admin-document-base-review`와 실제 업무·파일 형식에 맞는 전문 스킬을 적용하세요. 상세 공통 기준은 필요한 절만 확인하세요.
- 민원·부서 의견·확인 사실을 구분하고, 결론을 바꿀 시점·권한·예외·반대자료와 미확인 부분을 드러내세요.
- 실질적 사건 검토라면 `document-validation-pipeline`으로 검토 판단을 검증하고 문안의 일치를 확인하세요.
- 요청한 결과물 외의 분류표·계획표·상태 라벨·보조 파일은 실제 판단이나 재개에 필요할 때만 만드세요.
- 승인된 조사·수정은 계속 진행하고, 필수 정보 또는 별도 권한이 필요한 부분만 확인하세요. 실행·공급자·마스킹·외부 전송 경계는 현재 `AGENTS.md`를 따르세요.
