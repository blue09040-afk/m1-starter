# 교훈의 공통 지침 승격 프롬프트

다음 개선 후보를 공통 지침, 실행 키트, 반복 프롬프트 중 어디에 반영할지 검토하고 필요한 수정을 제안해 주세요.

## 입력

- 후보 교훈:
- 출처 작업:
- 반영 후보 파일:
- 기존 관련 지침:
- 사용자 요청:

## 검토 기준

1. 사건 고유 사실, 개인정보, 내부 문서번호, 담당자 정보가 제거되었는지 확인한다.
2. 기존 지침과 중복되거나 충돌하는지 확인한다.
3. 모든 사건에 적용할 규칙인지, 특정 문서·도구·검증 절차에만 적용할 규칙인지 구분한다.
4. 자동 적용하면 과도한 부담이 되는지 확인한다.
5. 반영 후 검증 방법과 남은 위험을 적는다.
