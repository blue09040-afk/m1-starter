# 자동검증 실행 프롬프트

`guides/BASE_INSTRUCTIONS.md`를 최상위 지침으로 적용하고, `document-validation-pipeline` 스킬에 따라 자동검증을 수행하세요.

공익신고 사건이면 `public-interest-report-review` 스킬도 함께 적용하세요.

## 검증 대상

다음 역할의 파일을 찾아 대조하세요. 파일명이 다르면 같은 역할의 파일로 대체하세요.

- 주장 분류표
- 소관부서 조사결과 대조표
- 작업 체크포인트 또는 확인 필요 목록
- 최종 회신문 또는 회신문 초안
- 법령 확인 자료 또는 법령 검토 메모

## 산출물

원본 문서는 수정하지 말고 `_validation/` 폴더에 다음 산출물을 작성하세요.

1. `validation_report.md`
2. `paragraph_source_map.md`
3. `unresolved_items.md`
4. `final_risk_summary.md`
5. `legal_check_log.md`

## 검증 기준

검증 결과는 다음 상태로 구분하세요.

- `[확인 완료]`
- `[확인 필요]`
- `[문안 수정 권고]`
- `[누락 가능]`
- `[위험]`

특히 다음 항목을 중점적으로 확인하세요.

- 근거 없는 문장
- 조사요청 쟁점 누락
- 잠정 판단의 확정 표현화
- 법령 확인 필요 사항의 확정 표현화
- 조치 예정·진행·완료 표현 오류
- 개인정보·비공개 정보 노출
- 내부 검토용 표현의 대외 문안 혼입
