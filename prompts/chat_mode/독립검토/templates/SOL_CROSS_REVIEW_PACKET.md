## 2. 1차 Sol 비교기준 스냅샷

1차 독립검토의 마지막에 작성된 스냅샷을 **원문 그대로** 붙인다.

```text

```

1차 스냅샷 원문이 없으면 기억이나 사후 요약으로 복원하지 않는다. 이 경우 `사전 독립판단 원문 없음`으로 표시하고, 엄밀한 1차-2차 교차검증이 아니라 현재 자료 기준의 비교검토로 범위를 낮춘다.

## 10. 패킷 작성자 자체검증

- [ ] 1차 Sol 스냅샷을 사후 수정·요약하지 않았는가
- [ ] 스냅샷이 없는데 기억으로 복원하지 않았는가
- [ ] Codex 결과와 Sol 결과를 명확히 분리했는가
- [ ] Codex의 결론을 객관적 사실처럼 재서술하지 않았는가
- [ ] 양측 차이를 미리 `중대/경미/누락`으로 판정하지 않았는가
- [ ] 차이 목록이 전체 비교를 대체하지 않는다는 점이 유지되었는가
- [ ] 원자료·법령의 실제 제공 범위와 생략 범위를 표시했는가
- [ ] 법령·시점·권한 충돌이 있으면 공식 근거 확인 상태를 표시했는가
- [ ] 문체 차이와 판단 차이를 구분했는가
- [ ] 1차 이후 새 정보와 사용자 확정 기준을 분리했는가
- [ ] 최근 사용자 확정 기준을 과거 판단에 소급 적용하지 않았는가
- [ ] 개인정보·비공개 정보를 필요 이상으로 넣지 않았는가
