# SOL_EXTERNAL_REVIEW

> 용도: 일반 ChatGPT Sol High가 1차 블라인드 독립검토, 2차 교차검증 또는 3차 레드팀 검토 결과를 **Codex가 다시 읽고 통합할 수 있는 구조화된 Markdown 결과물**로 남길 때 사용한다.
>
> 이 문서는 검토결과의 전달 형식을 정하는 템플릿이다. 공통 판단 기준이나 사건 고유 사실의 정본이 아니며, 패킷·원자료와 충돌하면 원자료와 공식 근거를 우선한다.
>
> **작성 강도:** 모든 절을 기계적으로 채우지 않는다. 현재 검토 단계와 사건 위험도에 필요한 절만 남기고, 해당 없는 빈 절은 삭제하거나 `해당 없음`으로 짧게 표시한다. 1차는 독립 판단과 스냅샷, 2차는 스냅샷 보존과 차이 검증, 3차는 최종 문안 위험검토에 집중한다.
