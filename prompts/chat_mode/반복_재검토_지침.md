# Chat 모드 반복 재검토 지침

## 적용 트리거

사용자가 **이미 한 작업물을 다시 보고 직접 고친 뒤 재검토를 반복하여 안정화하는 것**을 명시적으로 요청하면 적용한다.

대표 트리거는 다음과 같다.

- `반복 재검토`
- `반복검토`
- `재검토 반복`
- `수정 필요 없을 때까지 재검토해줘`
- `검토하고 직접 수정한 뒤 다시 재검토를 반복해줘`
- 위와 같이 반복 루프의 의도가 명확한 요청

`제3자 관점`, `처음 보는 입장` 같은 표현은 검토 방식일 뿐, 그것만으로 반복 재검토를 자동 실행하지 않는다. `독립검토`, `독립검토-1/2/3`은 이 지침의 트리거가 아니며 기존 `prompts/chat_mode/독립검토/` 체계를 우선한다.

## 실행 기준

상세 반복 절차와 종료 기준의 정본은 다음 파일이다.

- `skills/iterative-review/references/iterative_review_protocol.md`

Chat 모드에서는 현재 대화에서 실제로 확인 가능한 자료와 사용자 확정 조건만을 기준으로 다음을 수행한다.

1. 현재 결과물을 기준본으로 고정한다.
2. 처음 보는 제3자 관점에서 사실·근거·논리·법령·권한·시점·수치·개인정보·쟁점 누락을 다시 본다.
3. 실질적 문제가 있으면 가능한 범위에서 직접 수정한다.
4. 수정본을 다시 같은 관점으로 재검토한다.
5. 더 이상 정확성·완전성·정합성·안전성·실사용성에 영향을 주는 수정 필요가 없으면 종료한다.

문체 취향만 남은 경우 반복하지 않는다. 확인할 수 없는 사항은 추정하지 않고 `확인 필요`로 남긴다. 불필요하게 범위를 확장하거나 다른 결론을 억지로 만들지 않는다.

사용자가 `굵은 수정안`도 함께 요청하면 내용 반복 재검토를 먼저 끝낸 뒤 최종 안정본에 굵은 수정안 형식을 적용한다.
